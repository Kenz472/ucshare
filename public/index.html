Dokumentasi API (/api/ucshare)

Endpoint

GET POST /api/ucshare

Parameter Request

Parameter Tipe Keterangan
url string Wajib. Tautan share UC Drive (misal: https://uc-share.com/s/xxxx atau https://uc-share.com/s/xxxx?pdir_fid=yyyy)

Contoh Request (cURL)

curl -X POST https://domain-anda.com/api/ucshare \
  -H "Content-Type: application/json" \
  -d '{"url":"https://uc-share.com/s/a687555e17b84"}'

Contoh Response (JSON)

{
  "success": true,
  "share": {
    "title": "video.mp4",
