UC-Share API Docs

Kembali ke Home
GET /api/ucshare?url={link_ucshare}

Digunakan untuk mengambil data file dan link unduh/streaming secara langsung menggunakan query string.

POST /api/ucshare

Request Body dalam format application/json:

{
  "url": "https://uc-share.com/s/xxxxxx"
}

Contoh Response (JSON)

{
  "success": true,
  "share": {
    "title": "Video Folder",
    "author": "User123",
    "total_size_formatted": "120.5 MB"
  },
  "files": [ ... ],
  "videos": [
    {
      "file_name": "sample.mp4",
      "video_url": "https://...",
      "resolution": "1280x720",
      "duration": "10m 20s"
    }
  ]
}
